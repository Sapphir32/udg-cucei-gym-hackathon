# Campus Gym App

> Developed during a university hackathon focused on student wellness and accessibility.

## Project Overview

Campus Gym is a mobile application prototype designed to improve student access to university gym services through a modern and intuitive mobile experience.

The project focuses on simplifying reservations, workout tracking, schedules, and accessibility for students.

---

## Problem

Many university gym systems lack modern digital experiences, making it difficult for students to manage schedules and reservations efficiently.

This project was designed to create a cleaner and more accessible platform for students.

---

## Goals

- Improve student interaction with university gym services
- Simplify schedule and reservation management
- Create an intuitive and accessible interface
- Design a modern mobile experience for students

---

## Features

- Gym schedule visualization
- Reservation system
- Workout tracking
- User profile section
- Mobile-friendly interface
